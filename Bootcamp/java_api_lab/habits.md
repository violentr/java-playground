# Daily Habits

~45 min every weekday. Pick **one book subsection** from the current week — not a whole chapter.

---

## Habit 1 — One API slice → one tiny program (25 min)

- [ ] Read one subsection in *Java in a Nutshell* (current week chapter)
- [ ] Create one class in the matching `weekXX-XX-*/` folder (e.g. `Day01_HashMap.java`)
- [ ] Use **at least 3 calls** from today's API
- [ ] Program does one job: read input → transform with the API → print result
- [ ] Do **not** reimplement what the JDK already provides

## Habit 2 — Book  Javadoc together (15 min)

- [ ] Read the book section
- [ ] Open the matching package in [Java SE 17 API docs](https://docs.oracle.com/en/java/javase/17/docs/api/)
- [ ] Answer:
  - What problem does this API solve?
  - What is the main interface or class?
  - What is one method I will use again?

## Habit 3 — One-line index card (5 min)

- [ ] Write one sentence in [api-notes.md](api-notes.md) under the current week:
  - **When I need to ___, I use ___.**

## Friday (review day)

- [ ] Combine Mon–Thu APIs into **one** program in the current week folder
- [ ] Re-read your 4 index cards in [api-notes.md](api-notes.md) — delete any you cannot explain out loud
- [ ] If the combine exercise is hard, **repeat the week** before moving on
